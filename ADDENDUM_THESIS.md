# Clarification on Implementation

*Added 8th of October, 2026. The original thesis ("Final Thesis Updated.pdf") is unchanged.*

The submitted thesis describes V-Architect as using natural language
processing (NLP). This wording overstated the implementation. V-Architect
converts speech to text and matches the result against a predefined set of
voice commands. It does not perform natural language understanding or use
machine learning to interpret user intent.

This note is provided so the thesis is not read as claiming more than the
system does. The README describes the actual behavior and limitations.
